Part 1: Foundations

Key ideas

  • AI: software that performs tasks that normally need human intelligence.
  • Machine learning (ML): a branch of AI where systems learn patterns from data instead of following hand-written rules.
  • Deep learning: ML using neural networks with many layers.
  • Generative AI: deep learning models that create new content such as text, images, audio and code.

Example

A spam filter learns from labeled emails (ML). An assistant that drafts a reply to an email creates new text (generative AI).

2. Supervised and unsupervised ML models ~40 min

Key ideas

  • Supervised learning: training data has labels (the right answers). The model learns to predict them. Classification predicts a category; regression predicts a number.
  • Unsupervised learning: no labels. The model finds structure, such as clusters of similar customers or unusual data points.
  • Self-supervised learning: the labels come from the data itself, for example hiding a word and predicting it. This is how large language models are pretrained.

Example

Predicting house prices from size and location is supervised regression. Grouping shoppers by buying habits is unsupervised clustering.

Task

Label each as supervised or unsupervised: (a) detecting fraud from past fraud cases, (b) grouping news articles by topic with no tags, (c) predicting tomorrow's sales.

3. Generative AI as a subset of deep learning ~40 min

Key ideas

  • A neural network is layers of simple units with adjustable weights. Training nudges the weights to reduce an error (the loss).
  • Deep networks learn useful features by themselves, so you do not hand-design them.
  • Discriminative models tell things apart ("cat or dog?"). Generative models learn what the data looks like and can produce new examples.

Example

An image classifier outputs the label "cat". A generative image model outputs a new picture of a cat that never existed.

Task

In your own words, explain the difference between recognizing a cat and creating a cat. Aim for three sentences.

Part 2: Generative AI core

5. Defining generative AI: a formal approach ~40 min

Definition

Generative AI is a type of AI that creates new content based on what it learned from existing content. Training teaches the model the patterns in its data; at use time, a prompt goes in and new content comes out.

Key ideas

  • Foundation model: a large model trained on broad data, then adapted to many tasks.
  • Parameters: the learned weights. More parameters usually means more capacity, and more cost.
  • Output is sampled from probabilities, so the same prompt can give different answers.
  • The model learns patterns, not verified facts. It does not look things up unless connected to a tool.

Task

Write a 50-word definition of generative AI for a friend, using the words training, prompt and new content.

6. Transformers, hallucinations, and prompts ~50 min

Transformers

The architecture behind most modern generative AI. Its key mechanism, attention, lets the model weigh how much each word in the input matters to every other word. This captures context, for example what "it" refers to in a sentence.

Hallucinations

Output that is fluent but false or unsupported. Common causes: gaps or noise in training data, no grounding in real sources, missing context in the prompt, and the fact that generation is probabilistic.

Prompts

The input that steers the model. Prompt design is crafting it so the output is useful.

Task

Ask any chatbot a question about a small, obscure topic you know well. Mark every claim as correct, wrong or unverifiable.

8. Generative AI for code generation ~30 min

What it can do

  • Complete code as you type, or write a function from a plain-English comment.
  • Explain unfamiliar code, find bugs, write tests and documentation.
  • Translate code between languages.

Limits

  • It can produce code that looks right but fails or is insecure. Always run and review it.
  • Check licensing rules and never paste secrets or private code into untrusted tools.

Task

Prompt: Write a Python function that counts how many times each word appears in a text. Explain each line. Then ask the model to write three tests and run them.

Part 3: Generative AI deep dive

10. Inside a large language model ~60 min

The pipeline

  • Tokenization: text is split into tokens (words or word pieces).
  • Embeddings: each token becomes a list of numbers that captures meaning, so similar words sit close together.
  • Transformer layers: attention blends context into every token.
  • Next-token prediction: the model scores every possible next token, picks one, appends it, and repeats.

Controls

  • Temperature: low is predictable, high is varied and riskier.
  • Top-p / top-k: limit which candidates can be picked.
  • Context window: how much text the model can consider at once.

How models are trained

  • Pretraining: self-supervised learning on huge text collections.
  • Instruction tuning: examples of good answers teach it to follow requests.
  • Preference tuning (such as RLHF): human ratings steer it toward helpful, safer answers.

Task

Run one prompt five times at low and at high temperature. Write what changed.

11. Prompting and grounding ~60 min

Anatomy of a strong prompt

Role, task, context, constraints, output format, and optionally examples.

Before and after

Weak: "Tell me about solar power."

Strong: "You are a science teacher. Explain how solar panels work to a 14-year-old in under 150 words, with one everyday analogy and three bullet-point takeaways."

Techniques

  • Zero-shot: just ask. Few-shot: include examples of the style you want.
  • Chain-of-thought: ask for step-by-step reasoning on multi-step problems.
  • Iterate: refine the prompt based on what the output got wrong.

Grounding

Retrieval-augmented generation (RAG) fetches relevant passages from trusted documents and gives them to the model, so answers rest on real sources. Ask for citations and tell the model to say "not found" when the sources lack the answer.

Task

Take one weak prompt and improve it three times. Keep all versions and note what each change fixed.

12. Evaluation, risks and responsible use ~60 min

Main risks

  • Hallucination: confident errors.
  • Bias: models reflect patterns, including unfair ones, in their data.
  • Privacy: do not enter personal or confidential data into tools you do not trust.
  • Copyright and licensing: check the terms for training data and outputs.
  • Security: prompt injection, where hidden instructions in a document or page hijack the model.

Evaluating output

  • Check facts against primary sources.
  • Test on a fixed set of examples, including tricky ones.
  • Measure groundedness: is every claim supported by the sources provided?
  • Keep a human in the loop for anything high-stakes.

Task

Write a one-page personal policy: what you will use generative AI for, what you will never put into it, and how you will check its work.

Capstone project

Choose one small real workflow, such as summarizing study notes, drafting customer replies, or explaining code.

  • Design a prompt template using the six-part anatomy.
  • Test it on 10 varied inputs and record each result.
  • Log every hallucination, bias or formatting failure, and how you fixed it.
  • Submit the final prompt, the test log, and a one-page reflection on where AI helped and where it did not.

Check your understanding

  • Why is a spam filter not generative AI?
  • What does attention let a transformer do?
  • Give two reasons a model might hallucinate, and two ways to reduce it.
  • How does RAG differ from a plain prompt?
